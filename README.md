# streamx-bind

Бинды для **Razer Stream Controller X**: горячие клавиши, запуск программ, ввод текста и макросы. Работает напрямую с устройством, без Razer Synapse / Loupedeck.

## Установка

**Скачайте архив `StreamControllerX-<версия>.zip`** со страницы [Releases](https://github.com/sadef21/soft-streamdeck-controller/releases), распакуйте в любую папку и запустите `Stream Controller X.exe`. Node.js ставить не нужно: он уже лежит в архиве. При первом запуске создаётся `config.json` со стартовыми страницами — дальше всё настраивается в конфигураторе.

## Запуск

**Проще всего — дважды кликнуть `Stream Controller X.exe`.** Он запускает утилиту без окна (значок появится в трее) и открывает конфигуратор в браузере. Если утилита уже работает, просто открывает конфигуратор. С ключом `--background` браузер не открывается. В архиве релиза Node.js встроен (`node\node.exe`); в папке с исходниками нужен установленный [Node.js](https://nodejs.org) 20 или новее, а если не установлены зависимости, exe предложит поставить их сам.

Exe собирается из `launcher/Launcher.cs` компилятором, который уже есть в Windows: `powershell -ExecutionPolicy Bypass -File launcher\build.ps1`.

Запуск из консоли:

1. **Закройте Razer Synapse и Loupedeck**: устройство одновременно может работать только с одной программой.
2. Установите зависимости (один раз):
   ```bash
   npm install
   ```
3. Проверьте конфиг и запустите:
   ```bash
   npm run check
   ```
   ```bash
   npm start
   ```

При каждом нажатии в консоль выводится номер кнопки. Конфиг перечитывается автоматически, как только вы сохраните `config.json`, перезапуск не нужен.

Без окна утилита запускается через `start-hidden.vbs`, журнал тогда пишется в `bind.log`.

Одновременно может работать только одна копия утилиты. Если запустить вторую, она сообщит, что порт занят, и закроется.

## Обновления

Утилита проверяет последний релиз на GitHub при запуске и раз в 12 часов. Если вышла новая версия, пункт в меню трея меняется на «Доступно обновление…», а в конфигураторе на вкладке «Устройство» → «Обновления» появляется кнопка «Обновить до …» со списком изменений.

- **Папка из архива релиза:** утилита скачивает новый архив, закрывается на несколько секунд, файлы заменяются, и она запускается снова. `config.json`, `state.json`, `bind.log`, папки `icons` и `backups` не трогаются.
- **Папка-клон git:** выполняется `git pull`, при смене зависимостей — `npm install`, затем перезапуск.

## Сборка релиза

1. Поднимите `version` в `package.json`.
2. Соберите архив:
   ```bash
   npm run release
   ```
   В `dist\` появятся папка `StreamControllerX` и архив `StreamControllerX-<версия>.zip`: исходники, зависимости, `Stream Controller X.exe` и `node\node.exe` — тот Node, которым запущена сборка (под него собраны `canvas` и `koffi`). Личного `config.json` в архиве нет, вместо него `config.example.json`.
3. На GitHub: **Releases → Draft a new release**, тег `v<версия>` (например, `v1.1.0`), прикрепите архив и опубликуйте. Описание релиза показывается в конфигураторе как список изменений.

## Значок в трее

Пока утилита работает, в трее (у часов) висит её значок: зелёный — контроллер подключён, серый — нет.

- **Левый клик** открывает конфигуратор.
- **Правый клик** — меню:
  - «Открыть конфигуратор»;
  - «Показать окно ожидания»;
  - «Запускать вместе с Windows» — галочка кладёт ярлык на `Stream Controller X.exe --background` в папку автозагрузки и убирает его;
  - «Проверить обновления» — открывает раздел обновлений в конфигураторе (когда вышла новая версия, пункт называется «Доступно обновление…»);
  - «Открыть журнал» — `bind.log`;
  - «Перезапустить» и «Выход».

«Перезапустить» и «Выход» корректно закрывают сессию с контроллером, поэтому следующий запуск подключается сразу. Снимать утилиту через Диспетчер задач больше не нужно.

Если значок не нужен, запустите утилиту с `--no-tray`.

## Веб-конфигуратор

Пока утилита запущена, конфигуратор открывается в браузере по адресу **http://127.0.0.1:3210/** (или через ярлык `Конфигуратор.url`).

- Кнопки устройства нарисованы так же, как на его экране. Кликните по кнопке, чтобы изменить подпись, цвета, иконку и действие.
- **Иконки**: библиотека из 2000+ значков с поиском (можно по-русски) — они красятся под тему кнопок; эмодзи или своя картинка — они сохраняются как PNG в папку `icons`.
- **Действия**: сочетание клавиш (можно записать, просто нажав его), текст, запуск программы (кнопка «Обзор…» открывает меню «Пуск»), открыть ссылку или папку, макрос, переход на страницу.
- Страницы создаются, переименовываются и удаляются вкладками над устройством. Ссылки на страницу с других кнопок обновляются сами.
- Звёздочка на вкладке — стартовая страница, луна — окно ожидания. Любую страницу можно назначить на эти роли в её панели («Сделать стартовой», «Сделать окном ожидания»). Окно ожидания выбирается и на вкладке «Ожидание», там же его яркость. Если удалить стартовую, ею станет другая страница; если удалить окно ожидания, оно не появляется, пока не назначите новое. Об этом предупреждает окно подтверждения.
- Кнопки можно перетаскивать, чтобы поменять местами. Ctrl+C / Ctrl+V копируют кнопку, Delete очищает, стрелки выбирают соседнюю.
- Значок со стрелкой-курсором в панели кнопки «нажимает» её: действие выполняется так же, как с устройства (сохранённая версия). Удобно проверять, не дотягиваясь до контроллера.
- **Сохранить** (Ctrl+S) записывает `config.json`, и устройство сразу обновляется. Если нажать кнопку на устройстве, она подсветится в конфигураторе.
- **Ctrl+Z / Ctrl+Y** (или стрелки в верхней панели) отменяют и повторяют правки до сохранения. «Сбросить» возвращает версию из `config.json`.
- **Резервные копии**: перед каждым сохранением прежний `config.json` копируется в папку `backups`, хранятся последние 30. Вкладка «Копии» слева открывает любую из них — как несохранённые изменения, которые можно сохранить или отменить.
- **Экспорт и импорт страницы** — в настройках страницы справа. Файл `.streamx.json` содержит все кнопки и свои иконки, поэтому страницу можно перенести на другой компьютер. Импорт добавляет её новой страницей.

Конфигуратор доступен только с этого компьютера. Другой порт можно задать при запуске: `node bind.js --port=4000`.

## config.json

```json
{
  "brightness": 8,
  "startPage": "main",
  "pages": {
    "main": {
      "0": { "label": "Mute", "color": "#B71C1C", "icon": "lucide:volume-x", "action": { ... } }
    }
  }
}
```

- `brightness`: яркость от 0 до 10.
- `keyStyle`: вид кнопок.
  - Тёмные, цвет кнопки окрашивает иконку, кольца и огоньки:
    - `"graphite"` (по умолчанию) — одинаковые тёмные кнопки, цвет кнопки подсвечивает иконку и фон;
    - `"neon"` — чёрные кнопки со светящейся рамкой цвета кнопки;
    - `"black"` — только иконки и подписи на чёрном.
  - Цветные, цвет кнопки — это фон, содержимое рисуется цветом текста:
    - `"glass"` — со стеклянным бликом;
    - `"gradient"` — с переливом по диагонали;
    - `"flat"` — плоская заливка.
  - `"light"` — светлые кнопки: бледная заливка оттенком цвета, иконки и кольца его тёмным оттенком.

  В конфигураторе стиль выбирается плитками с образцом на вкладке «Устройство».
- `contentScale`: размер подписей и иконок относительно кнопки, от 0.3 до 1 (по умолчанию 1). В конфигураторе это ползунок «Отступ от края кнопки» в пикселях. Фон всегда заливает кнопку целиком.
- `layout`: где кнопки на экране устройства — `{ "columns": [7, 104, 201, 298, 395], "rows": [0, 96, 192], "size": 78, "inset": 1, "radius": 8 }`:
  - `columns` — левый край каждой из 5 колонок;
  - `rows` — верхний край каждого из 3 рядов;
  - `size` — сторона окошка;
  - `inset` — отступ всей кнопки (с фоном и рамкой темы) от края окошка, вокруг остаётся чёрное поле. По умолчанию 1 px: край окошка слегка закрывает экран;
  - `radius` — скругление углов кнопки в пикселях экрана (по умолчанию 8). Конфигуратор скругляет кнопки так же.

  Экран 480×288, окошки рамки над ним стоят не строго равномерно и у разных экземпляров чуть по-разному. Проще подогнать в конфигураторе: вкладка «Устройство» → «Подгонка под рамки». Пока она открыта, на устройстве вместо кнопок зелёные рамки с номерами, и каждое нажатие «−» / «+» сразу их двигает — все сразу или каждую колонку и ряд отдельно. Подгоните так, чтобы каждая рамка была видна в своём окошке одинаково со всех сторон, и сохраните.
- `longPressMs`: сколько миллисекунд держать кнопку для долгого нажатия (по умолчанию 500).
- `idle`: окно ожидания — страница, которая сама открывается, если кнопки не трогать. `{ "after": 60, "page": "Ожидание", "brightness": 3 }` — через 60 секунд, с яркостью 3. Любое нажатие возвращает кнопки и само по себе ничего не выполняет. Открыть его сразу можно кнопкой с действием `idle`.
- `idle.brightness`: яркость экрана, пока показано окно ожидания, от 0 до 10 (0 — экран гаснет). Не задана — как обычно. Первое нажатие возвращает кнопки и обычную яркость.
- `weather`: город для кнопок погоды — `{ "city": "Прага", "latitude": 50.09, "longitude": 14.42 }`. В конфигураторе его проще найти по названию на вкладке «Индикатор».
- `pages`: страницы кнопок. Между ними можно переключаться действием `page`.

Под каждой клавишей видна область экрана 78×78 px. Утилита рисует кнопки ровно в эти области, поэтому свои иконки удобнее всего делать квадратными.

### Кнопка

- `label`: подпись. Что здесь написано, то и видно на кнопке. Длинный текст переносится сам, `\n` переносит строку принудительно. Все подписи на странице рисуются одним размером шрифта, слишком длинная уменьшается отдельно. Оставьте подпись пустой, и кнопку будет видно издалека:
  - иконка крупнее;
  - в кольце крупное число и значок того, что измеряется («−» и «+» у кнопок громкости);
  - у сети и даты крупное значение с короткой единицей.
- `color`: цвет кнопки. В тёмных стилях и в «Светлом» он окрашивает иконку и индикаторы, в цветных это фон.
- `textColor`: цвет подписи. Работает только в цветных стилях; в тёмных подписи всегда светлые, в «Светлом» — тёмные.
- `icon`: иконка. Если не задана, подбирается по действию: клавиатура для сочетаний, глобус для ссылок и так далее.
  - `"lucide:mic"` — значок из встроенной библиотеки, красится в цвет темы.
  - `"icons/cat.png"` — своя картинка (PNG, JPG или GIF), путь относительно конфига.
  - `"none"` — без иконки.
- `iconColor`: свой цвет значка из библиотеки вместо цвета темы.
- `meter`: живые данные вместо иконки, обновляются раз в секунду:
  - `"volume"`, `"mic"` — громкость Windows и микрофона: кольцо с процентами, без звука — перечёркнутый значок;
  - `"cpu"`, `"gpu"`, `"ram"`, `"disk"` — загрузка процессора и видеокарты (как в Диспетчере задач), занятая память и диск, тоже кольцом с процентами;
  - `"netDown"`, `"netUp"` — скорость сети; `"uptime"` — сколько работает Windows;
  - `"time"`, `"date"` — часы и дата;
  - `"clock-h1"`, `"clock-h2"`, `"clock-colon"`, `"clock-m1"`, `"clock-m2"` — большие часы: пять кнопок в ряд складываются в «14:35». Цифра занимает всю кнопку, поэтому подписи у них нет;
  - `"weather"` — погода сейчас: температура, небо и значок (солнце, облака, дождь, снег…). Данные Open-Meteo, обновляются раз в 15 минут, нужен интернет. Город задаётся в `weather`;
  - `"nowPlaying"` — обложка, под ней название и исполнитель трека, на любой странице. Берётся Spotify, если он запущен, иначе плеер, который играет сейчас (браузер, YouTube). Пока трек есть, его название заменяет подпись кнопки; подпись видна, когда ничего не играет. Нажатие без своего действия ставит на паузу.
- `longPress`: действие, если удерживать кнопку дольше `longPressMs`. Обычное действие тогда выполняется при отпускании. В углу такой кнопки рисуется отметка.
- `toggle`: кнопка с двумя состояниями (вкл/выкл), справа вверху у неё горит точка. Внутри — как выглядит включённое состояние: `label`, `color`, `icon`, `iconColor`. Что не задано, берётся из выключенного. Ещё два поля:
  - `source` — откуда берётся состояние. `"self"` (по умолчанию) — переключается при каждом нажатии и запоминается между запусками в `state.json`. `"speakers"` / `"mic"` — включено, когда в Windows выключен звук / микрофон. Такая кнопка обновляется сама, даже если звук выключили мышкой.
  - `action` — другое действие во включённом состоянии (только для `"self"`).

```json
"13": {
  "label": "Микрофон", "icon": "lucide:mic", "color": "#ec407a",
  "action": { "type": "mute", "target": "mic" },
  "toggle": { "source": "mic", "label": "Микрофон\nвыключен", "icon": "lucide:mic-off", "color": "#c62828" }
}
```

### Действия

| type | Поля | Пример |
|---|---|---|
| `hotkey` | `keys`, `hold` (необязательно) | `{ "type": "hotkey", "keys": "ctrl+shift+m" }` |
| `text` | `text` | `{ "type": "text", "text": "Привет!" }` |
| `run` | `path`, `args`, `cwd` | `{ "type": "run", "path": "C:\\Program Files\\OBS\\obs64.exe" }` |
| `open` | `target` | `{ "type": "open", "target": "https://youtube.com" }` |
| `macro` | `steps`, `stepDelay` | см. ниже |
| `delay` | `ms` | только внутри макроса |
| `page` | `page` (`"back"` — назад) | `{ "type": "page", "page": "extra" }` |
| `volume` | `step` — шаг в процентах, `target`: `"speakers"` (по умолчанию) или `"mic"`. Пока кнопку держат, шаг повторяется: через 0,4 с и дальше каждые 0,1 с (у кнопок без долгого нажатия) | `{ "type": "volume", "step": -5, "target": "mic" }` |
| `volumeSet` | `value` — уровень от 0 до 100, `target` — как у `volume` | `{ "type": "volumeSet", "value": 50 }` |
| `mixer` | регулятор громкости во весь экран, `target` — `"speakers"` или `"mic"` (см. ниже) | `{ "type": "mixer", "target": "speakers" }` |
| `mute` | `target`: `"speakers"` или `"mic"` | `{ "type": "mute", "target": "mic" }` |
| `media` | `command`: `"playpause"`, `"next"`, `"prev"`, `"seek"` (+ `seconds`, минус — назад), `"shuffle"`, `"repeat"`, `"open"` — вывести окно плеера | `{ "type": "media", "command": "seek", "seconds": -10 }` |
| `player` | панель плеера во весь экран (см. ниже) | `{ "type": "player" }` |
| `idle` | сразу показать окно ожидания — «заблокировать» деку; первое нажатие только возвращает кнопки | `{ "type": "idle" }` |
| `system` | `command`: `"lock"` — заблокировать компьютер | `{ "type": "system", "command": "lock" }` |

**`media`** управляет тем же плеером, что показан на кнопке «Сейчас играет»: Spotify, если он запущен, иначе текущим. Ключи и вход в аккаунт Spotify не нужны — данные берутся из Windows.

**`volume`** меняет громкость звука или микрофона Windows без всплывающего окна. Громкость встаёт на ближайшее значение, кратное шагу: 47 → 50 → 55. Прибавление громкости включает звук, как в Windows. **`mute`** выключает и включает звук или микрофон.

**`mixer`** — регулятор громкости во весь экран. Вместо трёх кнопок на звук хватает одной: обычное нажатие выключает звук, а долгое (`"longPress": { "type": "mixer", "target": "speakers" }`) открывает регулятор:

```
[ −1  ] [ Без звука ] [ уровень ] [ К микрофону ] [ +1  ]
[ −5  ] [    25%    ] [   50%   ] [     75%     ] [ +5  ]
[ −10 ] [     0%    ] [ Закрыть ] [    100%     ] [ +10 ]
```

По бокам шаги (удержание повторяет), в центре пресеты (текущий подсвечен), сверху кольцо с уровнем, «Без звука» и переключение между звуком и микрофоном. Регулятор закрывается кнопкой «Закрыть», сменой страницы или сам через 5 секунд без нажатий.

**`player`** — такая же панель для плеера. Обычное нажатие на «Сейчас играет» ставит на паузу, долгое (`"longPress": { "type": "player" }`) открывает:

```
[  ⏮   ] [ Перемешать ] [ обложка ] [ Повтор ] [  ⏭   ]
[ −10 с ] [            ] [    ⏯    ] [        ] [ +10 с ]
[ −30 с ] [            ] [ Закрыть ] [        ] [ +30 с ]
```

Перемотку, перемешивание и повтор поддерживают не все плееры: что плеер не разрешает, показано бледным и не нажимается (браузеры, например, дают перематывать, но не перемешивать). Закрывается так же, как регулятор.

**`hold: true`** держит клавиши зажатыми, пока зажата кнопка. Подходит для push-to-talk.

**`run`** запускает `.exe`, `.bat`/`.cmd`, `.ps1` и ярлыки `.lnk`. **`open`** открывает ссылки, файлы, папки и пути вида `shell:Downloads`.

**Макрос** выполняет шаги по очереди:
```json
{ "type": "macro", "stepDelay": 50, "steps": [
  { "type": "hotkey", "keys": "ctrl+t" },
  { "type": "delay", "ms": 300 },
  { "type": "text", "text": "погода" },
  { "type": "hotkey", "keys": "enter" }
]}
```

### Названия клавиш

Сочетание записывается через `+`, регистр не важен.

- Модификаторы: `ctrl`, `shift`, `alt`, `win` (также `lctrl`, `rctrl`, `lshift`, `rshift`, `lalt`, `ralt`)
- `a`–`z`, `0`–`9`, `f1`–`f24`
- `enter`, `esc`, `tab`, `space`, `backspace`, `delete`, `insert`, `home`, `end`, `pageup`, `pagedown`, `up`, `down`, `left`, `right`, `printscreen`, `pause`, `capslock`, `apps`
- Медиа: `volumeup`, `volumedown`, `mute`, `playpause`, `nexttrack`, `prevtrack`, `stop`
- Цифровой блок: `num0`–`num9`, `numadd`, `numsubtract`, `nummultiply`, `numdivide`, `numdecimal`
- Знаки: `minus`, `equals`, `comma`, `period`, `slash`, `backquote`, `[`, `]`, `;`, `'`, `\`

Клавиши `f13`–`f24` удобно использовать как «свободные» бинды: в обычных программах они ни на что не назначены, но их можно повесить в настройках Discord, OBS и игр.

`text` печатает текст независимо от раскладки (Unicode), поэтому кириллица и эмодзи вводятся как есть.

## Ограничения

- Если активное окно запущено от администратора, Windows блокирует эмулированные нажатия. В таком случае запустите утилиту тоже от администратора.
- Некоторые игры с античитом игнорируют программный ввод.
